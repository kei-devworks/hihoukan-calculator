## タクミ売上カウンター

売れるたびにボタンで数え、1時間ごとに売上報告の定型文をコピーして送る。

見出しの下のボタンで画面を切り替える。**注文**（品目の ＋/−・合計・報告文）がいつもの画面で、開いたときはいつもここが出る。
**記録** でオーダーの記録と1時間ごとの推移を見られ、**レジ精算** でお金を数えて合計と比べられ、**品目** で単価を変えたり品目を足したりできる。切り替えのボタンは、下へスクロールしても上に残る。

### 毎日の流れ

1. **営業のはじめ**に開く。前の日の数字が残っていたら黄色い知らせが出るので、
   「0 に戻して今日を始める」を押し、赤くなった「長押しで全部 0 にする」を **長押し** する
2. 売れたら、その品目の **＋** を押す。押しまちがえたら **−**。少し前のお客さんの分を − したときは、
   画面の下に「20:55 のオーダーから1,000円を1つ減らしました［元に戻す］」と出る
   - 押した分は、お客さんの注文（オーダー）ごとにまとまって、画面の下の「今のオーダー」に出る（下の節）
3. **1時間ごと**に「報告文」の **コピー** を押し、いつもの送り先に貼り付けて送る
   - 報告時刻は、いまに一番近い「ちょうど」（20:29 なら 20:00、20:30 なら 21:00）が自動で入る
   - ちがう時刻で送りたいときは時刻の欄を変える。「今」で自動に戻る
4. 次の日のはじめに、また 0 に戻す（数字は自動では消えない）

### 今のオーダー

＋ を押すと、画面の下に「今のオーダー 21:05〜 3点 ￥2,500」が出て、押した品目が並ぶ。

- 品目ごとに「1,000円 3個 **＋2** → 5個」と出る。左が今日それまでの数、まん中がこのお客さんの分、右が今日の合計
- その行の **−** **＋** でも直せる。4品目めからはパネルの中でスクロールする（押した品目の行が見えるところまで動く）
- お客さんが終わったら **完了** を押す。押さなくても、最後に押してから3分たつと自動で閉じる。閉じたあとに押した分は、次のお客さんのオーダーになる
- 閉じたあとは「前のオーダー 21:05・3点 ￥2,500 ›」が小さく出る。押すと中身を出し直せる（×で閉じる）
- **このオーダーを取り消す** を押すと赤い「長押しでオーダーを取り消す」に変わり、長押しでそのオーダーの分を全部消す。
  画面の下に［元に戻す］が出る
- 「品目」の画面にいるあいだは「今のオーダー … ›」とだけ出る。押すと「注文」に戻る

### 会計（お釣り）

今のオーダーの **会計** を押すと、会計の画面が下から出る。上に「お会計」「お預かり」「お釣り」が同じ大きさで並ぶ。

1. 受け取ったお札・硬貨のボタン（**＋10,000**・**＋5,000**・**＋1,000**・**＋500**・**＋100**）を、**受け取った枚数だけ** 押す。押すたびにお預かりに足される。
   1,000円札2枚と500円玉なら 1,000・1,000・500。2,000円札は 1,000 を2回押す
2. お預かりの合計と内訳（1,000×2・500×1）、その下に **お釣り** が出る。足りないうちは「あと ￥300」
3. 押しまちがえたら **1つ戻す**（最後の1枚）、やり直すなら **0に戻す**
4. お釣りを渡して **完了**。**戻る** で閉じても、預かりは残る（今のオーダーに「預かり ￥3,000 → お釣り ￥500」と出る）。
   そのあと ＋ を押すと、次のお客さんのオーダーになる

お釣りがいらないときは、会計をしないで **完了** を押せばよい。前のオーダーの会計も、「前のオーダー」の **会計** でやり直せる。

### 前のオーダーを直す

「前のオーダー … ›」を押して **編集** を押すと、直す画面が下から出る。

- 品目ごとの **−** **＋** で数を変える。変えた行は色が付き、「2 →」と変える前の数が出る。上に「変更前 ￥2,500 → 変更後 ￥2,000」
- **＋ 品目を足す** で、そのオーダーになかった品目も足せる
- **変更を保存** を押すまでは数は変わらない（**やめる** で捨てる）。保存したら画面の下に［元に戻す］が出る
- 直したことはオーダーに残る。もう一度 **編集** を開くと「変更の記録」から **この変更の前に戻す** で戻せる
- 報告文を送ったあとに直したときは、次の報告文で直った数が出る
- オーダーごと消すときは **このオーダーを取り消す**（長押し）

### 記録と推移（押し忘れの確認）

「記録」の画面で、押した分をお客さんのオーダーごとに見返せる。

- 上に「28オーダー・最後の記録 21:12（8分前）」。最後に押した時刻がすぐわかる
- 1時間ごとに、オーダーの数・売上・横棒・その時間までの累計が並ぶ。いまの時間は開いている
- オーダーが1件もない時間は黄色で「記録なし（押し忘れ？）」と出る。押し忘れがないか思い出す目安にする
- 時間を押すと、その時間のオーダーが新しい順に並ぶ（時刻・品目・金額・点数）。直したオーダーには「変更 1回」
- 各オーダーの **編集** で直せる（[前のオーダーを直す](#前のオーダーを直す) と同じ画面）。取り消したオーダーは線が引かれて残り、**元に戻す** で戻せる
- 金額はいまの単価で計算する（合計・報告文と同じ）

### レジ精算（お金を数えて合計と比べる）

「レジ精算」の画面で、お金を数えてカウンターの合計と比べる。押し忘れ・押しまちがいに気づくため。

1. **売上のポケット** の枚数を、1万円札・5千円札・千円札・500円玉・100円玉ごとに入れる。額面ごとの金額と合計が出る
2. **硬貨の釣り銭準備金** は、500円玉・100円玉ごとに **開店時** と **いま** の枚数を入れる。差が「使った釣り銭」になる
   - 開店時の枚数は端末が覚える（毎日同じなら、一度入れればよい。リセットしても残る）
   - 準備金を使っていなければ **使っていない** を押す（いまの枚数に開店時の枚数が入る）
3. 下に「ポケットの合計 − 使った釣り銭 ＝ 売上のお金」と、カウンターの合計が並ぶ
   - **ぴったり合っています** なら終わり
   - **お金のほうが多い** ときは押し忘れがないか、**少ない** ときは押しまちがいやお釣りのまちがいがないか、「記録」で確かめる。
     差がどれかの単価と同じなら「（ソフト（共通） 1つ分と同じ額）」と出る
4. 数え直すときは **数え直す**（長押し）。ポケットといまの枚数が消える（開店時の枚数は残る）

お札の準備金は、準備金用のポケットの合計をそろえて入れ替えているので数えない。

### 引き継ぎ（交代・休憩）

交代や休憩のときは、前の人の端末の数を次の人の端末へ渡す。どの画面からでも、見出しの **引き継ぎ** を押す。

**前の人（渡す）**

1. **次の人に渡す** を押すと、その時点の数の QR コードと「16:42時点・43点・￥41,300」が出る
2. 次の人に、自分の端末で読み取ってもらう（下）。近くにいないときは **AirDrop・LINE などで送る** か **リンクをコピー** で送る

- QR に入るのは、その時点の品目ごとの数・足した品目・釣り銭準備金の開店時の枚数。このあと数えた分は入らないので、渡す直前に出す
- お金はそのまま次の人に渡す

**次の人（受け取る）**

1. 自分の端末で **引き継ぎ** → **前の人から受け取る**
2. **ゼロから引き継ぐ** か **休憩から戻った** を選ぶ（はじめは **ゼロから引き継ぐ** が選ばれている。休憩から戻ったときだけ切り替える）
   - **ゼロから引き継ぐ**: 交代でこの端末を使い始めるとき。この端末の数を、前の人の数に置き換える。
     この端末に今日の記録が残っていれば取り消して置き換える（長押し。取り消した記録は「記録」から元に戻せる）
   - **休憩から戻った**: 休憩の前に自分で数えた分は残し、休憩のあいだに代わりの人が増やした分だけ足す。
     同じ QR を2回読んでも二重にならない。この端末のほうが多い品目は減らさずに知らせる
3. 前の人の数を入れる
   - **QR を読み取る** → **カメラで読み取る** で、前の人の画面の QR を写す（初めはカメラの許可を聞かれる）
   - **報告文を貼る**: 前の人の報告文（または送られてきたリンク）を貼る。欄は報告文の全体が見える高さで、貼った分だけ伸びる
   - **打ち込む**: 前の人の画面を見て、品目ごとの欄に数を入れる
4. 品目ごとの数と、「前の人の合計 ￥41,300 と合っています」を確かめて **引き継ぐ**。
   休憩から戻ったときは、品目ごとに「この端末 9個 ＋3 → 12個」と足す分が出る

- 引き継いだ数は、お客さんのオーダーとは別の「引き継ぎ」として記録され、報告文・合計・レジ精算に入る。今のオーダーには入らない。
  「記録」では「16:42 引き継ぎ 前の人の 16:42時点の数」の行になり、それより前の記録のない時間は押し忘れとみなさない
- 引き継いだあと3分は、画面の下の **元に戻す** で戻せる
- 前の人が足した品目がこの端末になければ、引き継ぐときに「品目」に足す。報告文から入れるときは、名前のある品目は先に「品目」で同じ名前で足しておく
- 送られたリンクや、カメラアプリで読んだ QR を開くと Safari で開く。ホーム画面のアイコンで使っている人は、ページの中の **QR を読み取る** を使うか、
  リンクを **報告文を貼る** の欄に貼る（[数字の保存](#数字の保存)）

### リセット

「リセット」を押すと赤い「長押しで全部 0 にする」に変わる。4秒のうちに **1秒ほど長押し** すると全部 0 になる
（押している間、ボタンが左から濃くなる。途中で指を離すとやめる）。タップしただけでは消えない。
レジ精算の枚数も消える（釣り銭準備金の開店時の枚数は残る）。0 にしたあとは、画面の下に「全部 0 にしました［元に戻す］」が3分出る。押しまちがえたら［元に戻す］で戻せる
（ほかのボタンを押すと消える）。
単価の変更は 0 にしても残る。

### 品目と単価（単価を変える・品目を足す）

「品目」の画面で、見出し（◾️肉・◾️ソフト）ごとに単価を変えたり、品目を足したりできる。どちらも **その端末だけ** に効く。

- **単価を変える**: 金額を打つと単価が変わる（値段で呼ぶ串は名前も変わる）。見出しに「品目と単価（単価 1件 変更あり）」と出る。
  **単価をすべて既定に戻す** で元に戻る（足した品目はそのまま）
- **品目を足す**: 「＋ ◾️ソフトに品目を足す」を押し、名前と単価を入れて **足す**。その見出しのカードの最後に ＋/− つきで出て、
  報告文にもその見出しの中に入る。名前を空にすると、串と同じく値段で呼ぶ（画面は「7,000円」、報告文は「7,000×2」）
- 足した品目の名前と単価は、その場で直せる。**消す** を押すと赤い「長押しで消す」に変わり、長押しで消える（今日の記録からも消える。画面の下の［元に戻す］で戻せる）
- 足した品目は **この端末だけ** に出る。ほかの端末でも同じ名前で足す（引き継ぎで報告文を貼るときに読めるように）。
  ずっと売る品目は、ページの設定に書いてもらうと全部の端末に出る

値上げなどで**全端末の単価を変えるとき**は、端末ごとに変えずに、ページの設定（`src/pages/takumi/config.ts`）を直してデプロイする。

## ネコ・グリコ売上カウンター

ネコとグリコの両方の店で使う（ページの URL は `/neko/` のまま）。
弓道と手裏剣のステッカー（1,000円）・絵馬（500円）・手形（500円）を、**在庫の数から**売上にする。
売上は弓道と手裏剣で**分けて**出る。定型文のコピーはない。

```
売れた数 = 開店時の在庫 + 途中で追加した数 − 残数
売上     = 売れた数 × 単価
```

見出しの下のタブで **弓道** と **手裏剣** を切り替える。タブには、それぞれの売上と、精算を終えた印（✓）が出る。
1つのタブの中で「在庫 → 売上 → レジ精算 → 精算を終える」と、上から順に作業が終わる。

### 毎日の流れ

1. **開店時**に、品目ごとの在庫を「開店時」の欄に入れる
2. 途中で在庫を足したら、「追加」の欄に足した数を入れる。**2回以上足したときは合計**を入れる（10個と5個なら 15）
3. **閉店時など**に残りを数え、「残数」の欄に入れる。品目ごとに「売れた 18個 → ￥18,000-」と出る
4. その下の **レジ精算** で、その見出しのお金を数える（弓道と手裏剣は別々。数え方はタクミの[レジ精算](#レジ精算お金を数えて合計と比べる)と同じ）。
   売上のポケットと、硬貨の釣り銭準備金（開店時・いま）の枚数を入れると、その見出しの売上と比べる
   - お金のほうが多い・少ないときは、残数や追加の入れまちがい・お釣りのまちがいがないか確かめる
5. 合っていたら **弓道の精算を終える** を押す。タブに「✓」が付く。そのあとで数を直すとタブが「！」になり、もう一度押すよう知らせる
6. もう一方のタブでも同じようにする。いちばん下の「計算結果」に、**弓道の売上**と**手裏剣の売上**が分かれて出る（下に小さく両方の合計）

1日に2回数えるときは、1回目の残数を入れて途中の売上を見て、閉店時に残数を数え直して上書きすればよい。

### 次の日

次の日に開くと、前の日の数字が残っていることを黄色い知らせで教えてくれる。どちらかを押し、赤くなったボタンを **長押し** する。
どちらでも、レジ精算のポケットといまの枚数と精算の印は消える（釣り銭準備金の開店時の枚数は残る）。

- **残数を今日の開店時の在庫にする** — 前の日の残数が、そのまま今日の「開店時」に入る（追加と残数は空になる）。
  夜のうちに在庫が変わっていなければこちらが楽。残数を入れていなかった品目は空になるので、数えて入れる
- **全部消して始める** — 全部の欄が空になる。開店時に数え直して入れる

### 表示の意味

| 表示 | 意味 |
| --- | --- |
| 在庫 18個（残数を入れると計算します） | 開店時（＋追加）は入っている。残数を入れると売上が出る |
| 開店時の在庫を入れてください | 追加や残数はあるが、開店時が空。赤枠の欄に入れる |
| 残数が在庫（5個）より多くなっています | 入れまちがい。赤枠の残数を確かめる。直すまで売上には入らない |
| 入れかけ 1品目（売上に入っていません） | その見出しに、まだ計算できない品目がある |

- 空の欄と「0」は別物。売り切れたら残数に **0** を入れる。空のままだと計算されない
- 負の数や小数は入らない（欄から離れると元に戻る）
- 「リセット」は押すと赤い「長押しで全部消す」に変わり、**長押し** すると全部の欄が空になる（タップしただけでは消えない）

単価が変わったときは、ページの設定（`src/pages/neko/config.ts`）を直してデプロイする（画面からは変えられない）。

## 勤務時間報告

勤務日・勤務時間・休憩・交通費から、次の報告文を作ってコピーする。

```
勤務時間報告
10月14日(水曜日)
勤務時間　16:00 〜23:00
休憩時間　0分
交通費　（往復）500円
　　園田駅〜なんば駅
10月13日分受領済み
```

### 毎回の流れ

1. 開くと、**勤務日は今日**、**勤務時間・休憩・交通費は前回コピーしたときと同じ**ものが入っている。
   深夜 0 時を過ぎてから開いても、朝 4 時までは前の日が勤務日になる
2. ちがうところだけ直す
   - 勤務日: 日付の欄か「‹ 前の日」「今日」「次の日 ›」。報告が遅れたときは前の日に戻す
   - 勤務時間: 開始・終了の「時」と「分」（5分刻み）を選ぶ。下に実働が出る
   - 休憩: 「0分」「15分」…のボタン。ほかの長さは横の欄に分で入れる
   - 交通費: 登録したパターンをタップして切り替える。「交通費なし」も選べる
3. 報告文を確かめて **コピーして報告する** を押し、いつもの送り先に貼り付けて送る。
   押すと、勤務日と勤務時間がこの端末に記録される

### 受領済みの行（日払い）

- 日払いでは、最後の行に **前回の勤務日** を「10月13日分受領済み」として入れる（日払いは次の勤務日に前回分を受け取るため）
- 前回の勤務日は、コピーしたときの記録から自動で入る。「受領済みの勤務日」の欄で変えられ、「消す」で行を書かない
- **初めて使うとき**（記録がまだないとき）は、この行は書かない
- 勤務日を前の日に戻したときは、受領済みもその前の報告の日に合わせて変わる（手で変えていたらそのまま）
- 「給料の受け取り」を **月払い** にすると、受領済みの行は消える。次に開いたときも月払いのまま

### 交通費のパターン

- 「＋ パターンを追加」で、往復の金額と2つの駅を登録する（駅名の「駅」は付けても付けなくてもよい）
- いくつでも登録でき、タップで切り替える。最後に選んだものが次回も選ばれている
- 「編集」で金額や駅を直したり、パターンを消したりできる（消すのは2回押し）

### 書きかけ

入力した内容は、その日のうちならページを閉じたり再読み込みしても残る。次の日に開くと、前回コピーした内容から始まる。

## サイトをほかの人に教える

ポータル（ページの一覧）の右上の **共有** を押すと、このサイトの入口の QR コードが出る。

- 相手のスマホのカメラで QR コードを読み取ってもらうと、そのまま開ける
- 「AirDrop・LINE などで送る」でリンクを送ったり、「リンクをコピー」で貼り付けたりもできる（送る画面が出ない端末では「リンクをコピー」だけ）
- ホーム画面に追加して使う場合は、追加したあとはそのアイコンから開く。カメラや送られたリンクから開くと Safari で開き、
  保存の場所がホーム画面のアイコンとは別になる（[数字の保存](#数字の保存)）

## 数字の保存

- 押したり入れたりするたびに、**その端末のブラウザに自動で保存**される。再読み込みしても、ページを閉じて開き直しても残る
- 保存は「端末 × ブラウザ」ごと。**同じ端末でも、Safari と Chrome、ホーム画面に追加したアイコンは別々**に保存される。
  端末ごとに開き方を1つに決める
- **プライベートブラウズでは使わない**（タブを閉じると消える）。保存できない状態のときは、画面に赤い知らせが出る
- ほかの端末とは共有されない。2台で数えるときは、それぞれの結果を足す。交代・休憩のときは [引き継ぎ](#引き継ぎ交代休憩) で渡す
- 画面の上に「この端末に保存済み（最終更新 21:03）」と出ていれば保存できている

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| コピーを押すと「選択したので長押しでコピー」と出る | 報告文が選択された状態になっているので、長押しして「コピー」（勤務時間報告では、このときも勤務日と勤務時間は記録される） |
| 受領済みの日付がちがう | 別の端末やブラウザで報告した日は記録にないので、「受領済みの勤務日」の欄で直す |
| 数字が消えた | 別のブラウザやホーム画面のアイコンから開いていないか確かめる。iPhone の Safari は、7日間開かないと保存を消すことがある |
| 新しい単価・品目が出てこない | 更新の反映に最大10分ほどかかる。少し待って再読み込み |
| 引き継ぎの QR が読めない・カメラが映らない | 前の人の画面を明るくし、QR を枠に大きく写す。だめなら前の人に **リンクをコピー** で送ってもらい **報告文を貼る** に貼るか、**打ち込む** |
